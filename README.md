# SimpleTextEditor
Simple text editor using python, tkinter

Simple Text Editor

A basic text editor built using Python's Tkinter library. This application allows users to create, open, and save .txt files through a simple graphical user interface.

# Features
    New: Clear the text area and start a new document.
  
    Open: Open and read an existing .txt file.

    Save As: Save the current text to a .txt file.

# Keyboard Shortcuts:

    Ctrl + N – New file
    
    Ctrl + O – Open file
    
    Ctrl + S – Save file

# Requirements
    Python 3.9
    
    Tkinter (usually included with Python)
    
# How to Run
    Make sure Python is installed.
    
    Clone or download this repository.
    
    Open a terminal in the project folder.
    
    Run the following command:
    
    bash
    python text_editor.py
